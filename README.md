# MobileJackSoft

App móvil de La Coca de Jacks para clientes y domiciliarios.

- [`jacksoft_mobile/`](jacksoft_mobile/): la app en Flutter y Dart. El README de esa carpeta explica cómo correrla.
- [`jacksoft-mobile.html`](jacksoft-mobile.html): el prototipo de diseño en el que se basa.

Documentación del proyecto: [analisis](https://github.com/alejandrogomezmesa1/analisis). Frontend web: [jacksoft](https://github.com/Ryuksehen/jacksoft).
